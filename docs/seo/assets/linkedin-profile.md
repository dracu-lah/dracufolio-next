## 4. Custom URL

Go straight to the public profile editor, it skips the menus:

```
https://www.linkedin.com/public-profile/settings
```

The URL field is at the top right, with a pencil next to it.

**If you cannot find it:**

- **The phone app does not have this setting at all.** Custom URL editing is desktop browser
  only. On a phone, open the link above in Chrome and request the desktop site.
- **A narrow browser window hides it.** "Edit public profile & URL" sits in a right-hand
  sidebar on your profile page, and LinkedIn drops that sidebar below roughly 1100px wide.
  Maximise the window.

The long way: Me (top right) > Settings & Privacy > Visibility > Edit your public profile.

Set the URL to:

```
nevilkrishnak
```

If taken, try `nevilkrishna-k`, then `nevilkrishnakdev`.

On the same screen: **Your profile's public visibility** must be **On**, with every section
under it visible to everyone.

Send the final URL back as a dev task. The old one is hardcoded in four files in this repo.
