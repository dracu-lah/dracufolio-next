# SEO and marketing: the manual work

The site side is built. `/hire` and the 29 location pages, the blog, `llms.txt` and
`llms-full.txt`, the robots rules for AI crawlers, the sitemap with real dates and images, the
Person, ProfessionalService and WebSite schema, the short links and the WhatsApp button are all
live.

None of that ranks on its own. What is left is the part no code can do: claiming the profiles,
getting real reviews, asking real people for links, and publishing. This folder is that work,
broken into tasks that can be done one at a time.

Everything here is written to be done without googling anything. Exact buttons, exact text to
paste, exact commands.

## The order to do them in

Do them in number order. It is not arbitrary.

1. `01` first, because every other file points at `https://nevil.dev` and the address has to be
   settled.
2. `02` next, because nothing can be measured until Search Console is verified.
3. `03` next, because it takes the longest to pay off (verification, then reviews arriving over
   weeks) and everything else runs in parallel with it.
4. `04` next, because half the messages in `05` link to those profiles.
5. `05` and `07` after that, in either order.
6. `06`, `08`, `09`, `10` and `11` are reference and routine. Read them once, then use them
   when the situation comes up.

## Two rules for all of it

Never fake anything. No invented reviews, no written-for-them testimonials, no bought links, no
made-up numbers. Every one of them is reversible by the platform, and the reversal costs more
than the thing was ever worth.

Never break the facts apart. One name spelling, one phone format, one location string, one
website, everywhere. Consistency is doing more work here than any single tactic on this list.
